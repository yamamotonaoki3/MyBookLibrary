# MyBookLibrary 要件定義書

## 1. アプリ概要

文学賞の受賞・ノミネート作品の読書進捗管理と、お気に入り著者の管理を行うWebアプリケーション。
複数のユーザーが利用できる（ユーザー登録・ログイン機能あり）。

## 3. 機能要件

### 3.1 受賞・ノミネート作品一覧・読書進捗管理（必須）

- 賞ごとに受賞作品・ノミネート作品の**両方**を一覧表示する
- 受賞作品とノミネート作品をバッジやラベルで視覚的に区別する
- 各作品に「読んだ／未読」のステータスをチェックできる
- 読了率など進捗が一目でわかるUIを提供する

### 3.2 お気に入り著者管理（必須）

- 著者を「お気に入り」として登録できる
- お気に入り著者の一覧を表示する
- 著者名をクリックするとその著者の作品一覧を表示する
- 作品ごとに「読んだ／未読」をチェックして記録できる

### 3.3 新刊お知らせ（必須）

- お気に入り登録した著者が新刊を出した際にアプリ内通知を行う
- 次回ログイン時またはアプリ表示時に通知を表示する

### 3.4 著者ベースのおすすめ機能（あったらいい）

- 同じ著者をお気に入り登録している他ユーザーのデータを参照する
- 「この著者を登録しているユーザーはこの著者も読んでいます」という形でおすすめを表示する
- 協調フィルタリング的なアプローチ（著者単位）

### 3.5 近隣図書館の在庫連携（あったらいい）

- ユーザーが近くの図書館を登録できる
- 「読みたい」リストの本が登録図書館に在庫ありの場合、「図書館に入荷」タグを表示する
- 図書館APIの利用可否は要調査（カーリル等の公共図書館APIが候補）
- API利用不可の場合は手動タグ付けで代替する
