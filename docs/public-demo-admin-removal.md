# 公開済みデモ管理者の削除手順

1. README 掲載アカウントと対象環境変数が一致し、対象が `admin` であることを読み取り専用で照合する。値は記録しない。
2. 対象外の管理者が少なくとも 1 名いることを集計で確認し、その管理者本人にログイン確認を依頼する。
3. 暗号化済みの RDS 手動スナップショットを作成し、30 日後に削除する予定を記録する。
4. AWS SSM でのみ `PUBLIC_DEMO_ADMIN_EMAIL` と `PRODUCTION_DB_HOST` を注入し、まず dry-run を実行する。次に `--apply` を指定する。
5. 出力は件数と成否だけを #608 に記録する。メールアドレス、認証情報、個人データを残さない。

スクリプトは、対象が管理者でない・残存管理者がいない・接続先ホストが不一致の場合に停止する。削除は単一トランザクションで行い、対象の認証連携、セッション、読書状態、レビュー、いいね、通報、お気に入り、通知、フォロー、問い合わせ、監査ログを削除する。共有書籍は残し、作成者参照だけを `null` にする。完了後は対象を特定できない監査ログ 1 件だけを残す。
