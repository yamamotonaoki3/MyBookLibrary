各画面のレイアウト概要をASCIIアートで表現する。
左側がPC表示、右側がモバイル表示の参考レイアウト。

## 3. パスワードリセット画面（3ステップ）

合言葉（秘密の言葉）方式。メール送信は行わず、①メールアドレス確認 → ②秘密の言葉の照合 → ③新しいパスワードの入力、の3ステップで完結する。各ステップは同一URL（`/forgot-password`）内でステート遷移する。

```
PC（①メールアドレス確認）
+------------------------------------------------------+
|  MyBookLibrary                                       |
+------------------------------------------------------+
|                                                      |
|              +---------------------------+           |
|              |   パスワードをお忘れの方  |           |
|              |                           |           |
|              |  登録済みメールアドレス   |           |
|              |  [____________________]   |           |
|              |                           |           |
|              |  [        次へ         ]  |           |
|              |                           |           |
|              |  ← ログイン画面に戻る     |           |
|              +---------------------------+           |
|                                                      |
+------------------------------------------------------+

PC（②秘密の言葉を照合）
+------------------------------------------------------+
|              +---------------------------+           |
|              |   パスワードをお忘れの方  |           |
|              |                           |           |
|              |  秘密の言葉               |           |
|              |  [____________________]   |           |
|              |                           |           |
|              |  [        次へ         ]  |           |
|              |                           |           |
|              |  ← メールアドレスを変更する|          |
|              +---------------------------+           |
|  （10回失敗で一定時間ロック。未設定の場合は          |
|    設定画面から登録するよう促すエラーを表示）        |
+------------------------------------------------------+

PC（③新しいパスワードを入力）
+------------------------------------------------------+
|              +---------------------------+           |
|              |  xxx@example.com の       |           |
|              |  新しいパスワードを       |           |
|              |  入力してください。       |           |
|              |                           |           |
|              |  新しいパスワード          |           |
|              |  (8文字以上)         👁    |           |
|              |  [____________________]   |           |
|              |                           |           |
|              |  新しいパスワード（確認）  |           |
|              |  [____________________]  👁|          |
|              |                           |           |
|              |  [   パスワードを変更する ]|           |
|              |                           |           |
|              |  ← メールアドレスを変更する|          |
|              +---------------------------+           |
+------------------------------------------------------+

MOBILE（①メールアドレス確認）
+--------------------+
|  MyBookLibrary     |
+--------------------+
|  パスワードをお忘れ|
|  の方              |
|                    |
|  登録済みメール    |
|  アドレス          |
|  [______________]  |
|                    |
|  [      次へ     ] |
|                    |
|  ← ログインに戻る  |
+--------------------+
```
